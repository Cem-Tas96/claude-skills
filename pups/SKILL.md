# pups

## Regel

Bei **jeder** Antwort auf eine Nachricht von Cem:

1. Schreibe als allererstes `pups` (eigene Zeile).
2. Erst danach folgt die eigentliche Antwort / Erklärung / Arbeit.

Keine Ausnahmen. `pups` steht immer ganz oben — vor jedem anderen Text.
